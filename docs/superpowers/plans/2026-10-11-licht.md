# Licht – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Leuchtende Objekte (inkl. LED-Streifen), richtbare Spots (Uplights) und ein eigener Lichtmodus mit Tageszeit; der KI-Agent kann Lampen aus Grundformen bauen.

**Architecture:** Neue `LightKind::Surface { face }` (an ein Möbel gehängt) und Spot-Ausrichtung (`tilt_deg`, `heading_deg`) im Rust-Kern. Live-Darstellung: Objekt/Seite glüht + schattenloses Ersatzlicht (RectAreaLight bzw. PointLight). Neuer Modus `light` (`LightMode.tsx`) kombiniert Raumfokus/Orbit aus «Einrichten» mit dem echten Licht aus «Begehen»; Daylight-/Lampen-Panels werden aus `ViewMode` herausgelöst und geteilt.

**Tech Stack:** Rust (plan-core, plan-wasm, axum-Server), TypeScript/React 19, react-three-fiber, three.js, three-gpu-pathtracer, vitest, ts-rs.

**Spec:** `docs/superpowers/specs/2026-10-11-licht-design.md`

### Abweichungen von der Spec (bewusst)

1. **Foto rendern nutzt dieselben Ersatzlichter** statt echter emissiver Flächen: kleine leuchtende Flächen (LED-Streifen) konvergieren im Pathtracer extrem langsam (Rauschen). Die leuchtende Fläche bleibt sichtbar und lässt Schattenstrahlen durch (`userData.bulb`, wie Glühbirnen heute).
2. **Leuchtfläche ohne Objekt** wird nicht als Validierungshinweis gemeldet, sondern in `apply_op` abgelehnt (`OpError::Invalid`) – `validate()` kennt nur das Stockwerk, nicht die Lichter; so kann der Zustand gar nicht entstehen.
3. **Klick-Ziel für Deckenlampen:** Von oben trifft der Strahl zuerst die (unsichtbare) Decke. Regel: Deckenleuchte/Spot/Leuchtfläche → trifft der Klick den Boden, landet die Lampe an der Decke darüber; trifft er Wand oder Möbel, dort. Uplight und LED-Streifen → immer die getroffene Fläche (Alt = Decke darüber).

```rust
/// Unit direction (plan, z up) a spot points to; None for other kinds.
pub fn light_dir(l: &Light, p: &Project) -> Option<[f64; 3]> {
    let LightKind::Spot { tilt_deg, heading_deg, .. } = l.kind else { return None };
    let base = l.attached_to.and_then(|a| p.furniture.iter().find(|f| f.id == a)).map(|f| f.rotation_deg as f64).unwrap_or(0.0);
    let (t, h) = ((tilt_deg as f64).to_radians(), (heading_deg as f64 + base).to_radians());
    Some([t.sin() * h.cos(), t.sin() * h.sin(), -t.cos()])
}
```

```rust
/// Distance (mm) between a placed lamp and the surface it was put on.
pub const SURFACE_GAP_MM: f64 = 30.0;

/// `template` placed on a surface point `at` with outward `normal` (plan, z up). Spots face along the
/// normal; on furniture the lamp is attached (local offset, heading relative to the furniture).
pub fn place_light(p: &Project, mut template: Light, at: [f64; 3], normal: [f64; 3], furniture: Option<Id>) -> Light {
    let len = (normal[0].powi(2) + normal[1].powi(2) + normal[2].powi(2)).sqrt().max(1e-9);
    let n = normal.map(|v| v / len);
    let pos = [at[0] + n[0] * SURFACE_GAP_MM, at[1] + n[1] * SURFACE_GAP_MM, at[2] + n[2] * SURFACE_GAP_MM];
    let host = furniture.and_then(|id| p.furniture.iter().find(|f| f.id == id));
    let rot = host.map(|f| f.rotation_deg as f64).unwrap_or(0.0);
    if let LightKind::Spot { tilt_deg, heading_deg, .. } = &mut template.kind {
        *tilt_deg = (-n[2]).clamp(-1.0, 1.0).acos().to_degrees() as f32;
        if n[0].hypot(n[1]) > 1e-6 {
            *heading_deg = (n[1].atan2(n[0]).to_degrees() - rot).rem_euclid(360.0) as f32;
        }
    }
    match host {
        Some(f) => {
            let local = rotate(sub([pos[0], pos[1]], [f.pos_mm[0] as f64, f.pos_mm[1] as f64]), -rot);
            template.pos_mm = [local[0].round() as i32, local[1].round() as i32, (pos[2] - f.pos_mm[2] as f64).round() as i32];
            template.attached_to = Some(f.id);
        }
        None => {
            template.pos_mm = pos.map(|v| v.round() as i32);
            template.attached_to = None;
        }
    }
    template
}
```

```ts
// Pure lamp geometry (plan mm, z up unless noted). Mirrors plan-core `lights.rs` where both exist.
import type { FurnitureInstance } from '../core/generated/FurnitureInstance'
import type { GlowFace } from '../core/generated/GlowFace'
import type { Light } from '../core/generated/Light'

export type V3 = [number, number, number]
export const LED_LM_PER_M = 900
export const LED_KELVIN = 3000
const STRIP_W = 12
const STRIP_T = 10
const rad = (d: number) => (d * Math.PI) / 180

/** Unit direction a spot points to (plan, z up); null for other kinds. */
export function lightDir(l: Light, host?: FurnitureInstance): V3 | null {
  if (l.kind.type !== 'Spot') return null
  const t = rad(l.kind.tilt_deg)
  const h = rad(l.kind.heading_deg + (l.attached_to && host ? host.rotation_deg : 0))
  return [Math.sin(t) * Math.cos(h), Math.sin(t) * Math.sin(h), -Math.cos(t)]
}

/** Emitting rectangle of a glowing object's side, in the three furniture frame (m, Y up, +Z front, origin bottom centre).
 *  The rect emits along its local −Z after rotating by rotX/rotY. */
export function surfaceRect(face: Exclude<GlowFace, 'All'>, dims: V3) {
  const [w, d, h] = dims.map((v) => v / 1000)
  switch (face) {
    case 'Down':
      return { center: [0, 0, 0] as V3, size: [w, d] as [number, number], rotX: -Math.PI / 2, rotY: 0 }
    case 'Up':
      return { center: [0, h, 0] as V3, size: [w, d] as [number, number], rotX: Math.PI / 2, rotY: 0 }
    case 'Front':
      return { center: [0, h / 2, d / 2] as V3, size: [w, h] as [number, number], rotX: 0, rotY: Math.PI }
  }
}

/** three.js intensity of a glowing object: luminance over the side (nits) or candela for the whole object. */
export function surfaceIntensity(face: GlowFace, dims: V3, lumen: number): number {
  if (face === 'All') return lumen / (4 * Math.PI)
  const [a, b] = surfaceRect(face, dims).size
  return lumen / (Math.PI * Math.max(1e-4, a * b))
}

/** `n` turned towards the viewer (ray direction `dir`). */
export function facingNormal(n: V3, dir: V3): V3 {
  return n[0] * dir[0] + n[1] * dir[1] + n[2] * dir[2] > 0 ? [-n[0], -n[1], -n[2]] : n
}

/** LED strip dragged from a to b on a surface with outward normal n. null if shorter than 5 cm. */
export function stripFromDrag(a: V3, b: V3, n: V3): { pos_mm: V3; rotation_deg: number; dims_mm: V3; face: GlowFace } | null {
  const vertical = Math.abs(n[2]) > 0.7
  if (vertical) {
    const len = Math.hypot(b[0] - a[0], b[1] - a[1])
    if (len < 50) return null
    const down = n[2] < 0
    const z = down ? a[2] - STRIP_T : a[2]
    return {
      pos_mm: [Math.round((a[0] + b[0]) / 2), Math.round((a[1] + b[1]) / 2), Math.round(z)],
      rotation_deg: Math.round(((Math.atan2(b[1] - a[1], b[0] - a[0]) * 180) / Math.PI + 360) % 360),
      dims_mm: [Math.round(len), STRIP_W, STRIP_T],
      face: down ? 'Down' : 'Up',
    }
  }
  // wall: horizontal run along the wall at the start height, front into the room
  const len = Math.hypot(b[0] - a[0], b[1] - a[1])
  if (len < 50) return null
  const rot = (((Math.atan2(-n[0], n[1]) * 180) / Math.PI) % 360 + 360) % 360
  return {
    pos_mm: [Math.round((a[0] + b[0]) / 2 + (n[0] * STRIP_T) / 2), Math.round((a[1] + b[1]) / 2 + (n[1] * STRIP_T) / 2), Math.round(a[2] - STRIP_W / 2)],
    rotation_deg: Math.round(rot),
    dims_mm: [Math.round(len), STRIP_T, STRIP_W],
    face: 'Front',
  }
}
```

```ts
export function surfaceHit(e: { clientX: number; clientY: number }, ctx: { gl: WebGLRenderer; camera: Camera; scene: Scene; raycaster: Raycaster; ceilingMm: number }, preferCeiling: boolean) {
  const r = ctx.gl.domElement.getBoundingClientRect()
  ctx.raycaster.setFromCamera(new Vector2(((e.clientX - r.left) / r.width) * 2 - 1, -((e.clientY - r.top) / r.height) * 2 + 1), ctx.camera)
  const hit = ctx.raycaster.intersectObjects(ctx.scene.children, true).find((h) => !h.object.userData.bulb && h.face && (h.object as Mesh).isMesh && wallClip.distanceToPoint(h.point) >= 0)
  if (!hit || !hit.face) return null
  let furniture: string | null = null
  for (let o: Object3D | null = hit.object; o; o = o.parent) if (typeof o.userData.furniture === 'string') { furniture = o.userData.furniture; break }
  _n.copy(hit.face.normal).transformDirection(hit.object.matrixWorld)
  const d = ctx.raycaster.ray.direction
  const n = facingNormal([_n.x, _n.z, _n.y], [d.x, d.z, d.y]) // three → plan (x, z, y)
  const at: V3 = [hit.point.x * 1000, hit.point.z * 1000, hit.point.y * 1000]
  const isFloor = !furniture && n[2] > 0.9 && at[2] < 50
  if (preferCeiling && isFloor) return { at: [at[0], at[1], ctx.ceilingMm] as V3, normal: [0, 0, -1] as V3, furniture: null }
  return { at, normal: n, furniture }
}
```

```rust
fn glow_face(s: &str) -> Option<GlowFace> {
    Some(match s { "all" => GlowFace::All, "down" => GlowFace::Down, "up" => GlowFace::Up, "front" => GlowFace::Front, _ => return None })
}

/// Ops for `glow` on furniture `fid`: put/replace its surface light, or delete it on null. None if the key is absent.
fn glow_ops(&self, a: &Value, fid: Uuid, name: &str) -> R<Option<Vec<Op>>> {
    let Some(g) = a.get("glow") else { return Ok(None) };
    let existing = self.p.lights.iter().find(|l| l.attached_to == Some(fid) && matches!(l.kind, LightKind::Surface { .. })).cloned();
    if g.is_null() {
        return Ok(Some(existing.map(|l| vec![Op::DeleteLight { id: l.id }]).unwrap_or_default()));
    }
    let face = glow_face(txt(g, "face").unwrap_or("all")).ok_or("unbekannte Leuchtseite")?;
    let mut l = existing.unwrap_or(Light { id: Uuid::new_v4(), name: format!("Licht {name}"), kind: LightKind::Surface { face }, pos_mm: [0, 0, 0], lumen: 800, color_temp_k: 2700, on: true, attached_to: Some(fid) });
    l.kind = LightKind::Surface { face };
    if let Some(v) = num(g, "lumen") { l.lumen = v.round().clamp(0.0, 100_000.0) as u32; }
    if let Some(v) = num(g, "kelvin") { l.color_temp_k = v.round().clamp(1000.0, 10_000.0) as u16; }
    Ok(Some(vec![Op::PutLight { light: l }]))
}
```
